About AI Trading Copilot

Version 1.0.0 — AI-powered trading analysis companion for TradingView and other platforms.

Features: Technical analysis (SMA, EMA, RSI, MACD, ADX, Bollinger, VWAP), pattern recognition, trend analysis, support/resistance, volume analysis, risk assessment, and AI-powered explanations.

Data sources: Binance API (primary), CoinGecko (fallback). All analysis is performed locally. Backend saves analysis history for accuracy tracking.
